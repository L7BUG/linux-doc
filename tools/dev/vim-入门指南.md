# Vim 入门指南

## 1. 认识 Vim

Vim（Vi IMproved）是一个**模式化**的终端文本编辑器。它的核心设计与其他编辑器完全不同：编辑操作像一门语言——**动词 + 对象**，而不是"菜单 + 快捷键"。

### 1.1 为什么值得学

- **无处不在**：`vi` 是 POSIX 标准，任何 Linux 服务器上必然存在；`git commit`、`crontab -e`、`sudo visudo` 默认都用它
- **服务器上唯一可靠的编辑器**：`ssh` 进远程机器，Vim 是零安装成本的编辑方案
- **效率上限极高**：熟练后文本操作可以不离开键盘中央区域（home row）

### 1.2 安装与入门路径

```bash
# Arch Linux
sudo pacman -S vim

# 官方入门教程（强烈建议先跑一遍，约 30 分钟）
vimtutor
```

学习路径：**`vimtutor` → 本文档 → 日常使用 2 周 → 个性化配置**。`vimtutor` 是 Vim 自带的交互式教程，边做边学，比任何视频都有效。

## 2. 核心思想：模式（Mode）

Vim 与传统编辑器的根本区别：键盘**默认不是用来输入文字的**，而是用来发命令的。

| 模式 | 作用 | 进入方式 | 退出方式 |
|------|------|---------|---------|
| Normal（普通） | 发命令、移动光标（默认模式） | 任意模式下按 `Esc` | — |
| Insert（插入） | 输入文字 | `i`（光标前）/ `a`（光标后）/ `o`（新行） | `Esc` |
| Visual（可视） | 选中文本 | `v`（字符）/ `V`（整行）/ `Ctrl-v`（块） | `Esc` |
| Command（命令行） | 执行命令 | `:`（如 `:w` 保存） | `Esc` |

> **新手最大的坑**：进得去出不来。在任何地方按 `Esc` 都会回到 Normal 模式；想保存退出用 `:wq`，不保存强制退出用 `:q!`。

**思维转变**：在 Normal 模式下，你要先想"**我要对什么做什么**"，然后组合按键——比如 `dw` = delete word（删除一个单词），`y$` = yank to end of line（复制到行尾）。

## 3. 高频操作（日常 80%）

### 3.1 移动

| 按键 | 动作 | 按键 | 动作 |
|------|------|------|------|
| `h` `j` `k` `l` | 左/下/上/右 | `w` `b` | 下一个/上一个单词词首 |
| `0` | 行首 | `$` | 行尾 |
| `gg` | 文件开头 | `G` | 文件末尾 |
| `:42` | 跳到第 42 行 | `Ctrl-f` `Ctrl-b` | 翻页/翻上页 |

### 3.2 编辑（操作符语法）

Vim 编辑的精髓：**操作符 + 移动目标**。

| 操作符 | 含义 |
|--------|------|
| `d` | delete（删除） |
| `y` | yank（复制） |
| `c` | change（删除并进入 Insert） |
| `p` | put（粘贴） |
| `u` / `Ctrl-r` | 撤销 / 重做 |

组合示例：

| 命令 | 含义 | 命令 | 含义 |
|------|------|------|------|
| `dw` | 删一个单词 | `dd` | 删整行 |
| `d$` | 删到行尾 | `yy` | 复制整行 |
| `x` | 删光标处字符 | `cc` | 删整行并进入插入 |
| `p` | 粘贴到光标后 | `u` | 撤销 |

> 这个语法可以无限组合：`d3w`（删 3 个单词）、`c2w`（改 2 个单词）。理解"操作符 + 数量 + 目标"比背命令高效得多。

### 3.3 速查表

| 场景 | 命令 |
|------|------|
| 保存 | `:w` |
| 保存退出 | `:wq` |
| 不保存退出 | `:q!` |
| 撤销 / 重做 | `u` / `Ctrl-r` |
| 删除一行 / 撤销刚删的 | `dd` / `u` |
| 复制粘贴一行 | `yy` / `p` |
| 跳到文件头 / 尾 | `gg` / `G` |
| 进入插入 | `i` `a` `o` |
| 退出插入 | `Esc` |

## 4. 进阶操作

### 4.1 搜索与替换

```vim
/pattern      " 向下搜索（?pattern 向上）
n / N         " 下一个 / 上一个匹配
:s/old/new/   " 替换当前行第一个匹配
:s/old/new/g  " 替换当前行全部匹配
:%s/old/new/g " 替换整个文件
:%s/old/new/gc " 每个匹配都确认
```

> 替换命令的公式：`[范围]s/旧/新/[标志]`。范围 `%` = 全文件，标志 `g` = 全部、`c` = 确认。

### 4.2 多文件与缓冲区

| 命令 | 含义 |
|------|------|
| `:e path/to/file` | 打开文件 |
| `:ls` | 列出缓冲区（已打开的文件） |
| `:bn` `:bp` | 下一个 / 上一个缓冲区 |
| `:bd` | 关闭当前缓冲区 |

### 4.3 分屏

| 命令 | 含义 |
|------|------|
| `:sp` / `:vs` | 水平 / 垂直分屏 |
| `Ctrl-w` + `hjkl` | 在分屏间移动 |
| `Ctrl-w` + `=` | 均分窗口 |

### 4.4 重复与宏

- `.`：**重复上一次修改**——手动批量操作的利器（比如连续注释多行）
- 宏录制：`qa` 开始录制到寄存器 a → 执行操作 → `q` 停止 → `@a` 回放，`5@a` 回放 5 次

## 5. 配置入门（~/.vimrc）

Vim 开箱可用，以下配置解决 90% 的初始不适：

```vim
" 基础
set number              " 显示行号
set relativenumber      " 相对行号（移动时用）
set cursorline          " 高亮当前行
set tabstop=4           " Tab = 4 空格
set expandtab           " 用空格代替 Tab
set autoindent          " 自动缩进

" 体验
syntax on               " 语法高亮
set hlsearch            " 搜索高亮
set incsearch           " 输入时即时搜索
set ignorecase          " 搜索忽略大小写
set smartcase           " 但包含大写时区分

" 剪贴板（Linux 需装 vim-gtk 或 neovim 才支持）
set clipboard=unnamedplus
```

> 配置改动即时生效：`:so ~/.vimrc` 重新加载，无需重启。

## 6. 学习路径建议

| 阶段 | 时间 | 目标 | 方法 |
|------|------|------|------|
| 入门 | 1 天 | 理解模式、会基本编辑 | `vimtutor` + 本文档第 2、3 章 |
| 适应 | 1–2 周 | 日常编辑不再用鼠标 | 小文件强制用 Vim，查速查表 |
| 熟练 | 1 个月 | 移动/编辑无停顿 | 看 vim 内置帮助 `:help`，学 `.` 重复和宏 |
| 进阶 | 持续 | 多文件、分屏、配置化 | 写 `.vimrc`，了解插件（可选） |

## 7. 常见问题

**Q1：打开 vim 后不知道怎么退出？**
`:q` 退出；有未保存修改时 `:q!` 强制退出不保存；`:wq` 保存并退出。

**Q2：Insert 模式下想移动光标，能用方向键吗？**
能用，但会养成坏习惯——移动请按 `Esc` 回到 Normal 模式用 `hjkl`。Vim 效率的核心就在于手不离开键盘中央。

**Q3：不小心删了一大段内容怎么恢复？**
立即按 `u` 撤销；如果撤销过头了 `Ctrl-r` 重做。实在恢复不了，只要文件保存过，`:e!` 重新载入磁盘版本。

**Q4：vim 和 neovim 有什么区别？**
Neovim 是 vim 的现代化重写（内置 LSP 支持、更好的插件生态）。命令和配置 95% 兼容，学 vim 的知识直接迁移。终端里装了哪个用哪个，初学没有差别。

**Q5：搜索和替换时不想要高亮残留？**
`:nohlsearch` 清除高亮（或配置里加 `nnoremap <Esc> :nohlsearch<CR>` 一键清除）。
